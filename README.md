# 企业 AI 转型技能包

基于 Ramp 全员 AI 转型实践提炼的企业落地方法。Ramp 的公开结果：AI 使用量同比增长 **6300%**、**99.5%** 员工使用 AI 工具、非工程师贡献了 **12%** 的生产代码。

## 九项核心技能

1. **文化驱动型转型**：不写三个月战略白皮书，用领导示范、AI 公会、分享频道、公开表彰与使用追踪推动采纳。
2. **四级能力模型**：L0 偶尔使用 → L1 基础工具 → L2 构建自动化应用 → L3 构建让所有人提效的基础设施，对应 0x~10x 生产力。
3. **快速迭代与拥抱淘汰**：工具保质期以周计，执着于问题而不是工具。
4. **辐射型组织架构**：中央团队建平台与管道，职能团队在平台上构建应用，反馈驱动路线图；避免全中央化产能不足与全去中心化重复建设。
5. **零门槛工具平台**：安装即配置、SSO 一次登录、30+ 工具直接可用，不需要看文档或提工单。
6. **技能市场与组织复利**：任何人可把工作流打包成技能分享给全公司。
7. **排行榜驱动**：用团队与个人的使用数据形成健康的同伴压力。
8. **拆掉障碍**：无限学习预算、取消 token 上限、消灭 IT 瓶颈。
9. **非工程师赋能**：让销售、财务、风控、法务自己构建工具。
